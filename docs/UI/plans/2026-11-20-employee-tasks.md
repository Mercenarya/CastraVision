# Employee assigned tasks implementation plan

Execute sequentially/native; user approved backend + Supabase local exception and minimal task model. No new approval gate for the authorized implementation; hosted remains separate. No Git mutations/env/dependencies/reset. Spec: `docs/UI/specs/2026-11-20-employee-live-workflows.md`.

## 1. Database contract and authorization
- [x] pgTAP red: `15_employee_tasks.test.sql`, then migration generated by pinned CLI `20261120104659_employee_assigned_tasks.sql`.
- [x] `workspace_tasks`: workspace/team/campaign, assignee, assigner, title/description, optional due/proposal, status/version/request, timestamps. No sprint table; operational completed does not approve proposal.
- [x] `employee_tasks(workspace, command, data)` list/summary/detail/candidates/create/update. Actor from auth.uid and fresh role. Employee sees/updates own; Leader assigned Teams; MM workspace; candidate list operator-only. Scope immutable. Version + create request idempotency, linked proposal must be assignee's same campaign/Team.
- [x] SELECT-only authenticated table grant + own/team RLS, private helper, Active policy/write trigger + audit trigger. No public/anon execute, explicit definer search_path. Test old JWT after Team removal/Inactive, foreign scope, PII, role/payload injection, duplicate/stale, no direct writes.

## 2. API transport
- [x] `CastraServices/employee_api.py`, URLs, explicit RPC allowlist, dedicated unit tests. POST `/api/employee/<command>/`, narrow allowlist, body limit, verified workspace decorator, forwarded user token. No service CRUD.
- [x] Real local Auth/API fixtures in existing employee audit; no credentials output or hosted. Full SQL/Django regressions.

## 3. Functional UI
- [x] `services/employeeTasks.js`, guarded hook, task list/detail/search/status/campaign/page. Employee status/proposal link only; no assignment editor.
- [x] Reusable operator task assignment panel under campaign detail and MM personnel; candidates filtered by campaign Team; create/read-back. Retain original role permissions.
- [x] Dashboard priority list/task counts from task summary, task badge real; sprint unavailable. Task→proposal link navigates exact ID. Reload and request cancellation/identity isolation.
- [x] Frontend regression and real local UI with create→Employee update→link→read-back, role negatives. Lint/build/full suites/diff/secret scan, update remediation matrix and rollout limitations.

Lifecycle: todo/in_progress/blocked/completed; assignee may reopen completed to in_progress. Operator may also cancel; cancelled terminal. Completed is not content approval. Task assignment immutable in this minimal version (new assignment is a new task); no delete endpoint. Deadline optional timezone-qualified instant, no fabricated due dates.
