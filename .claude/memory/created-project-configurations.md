Created rule and skill files for the CastraVision project in the .claude directory to help maintain code quality and provide development guidance.

**What was created:**
- .claude/rules/code-review-rules.md - Comprehensive code review guidelines
- .claude/rules/project-guidelines.md - Overall project guidelines and workflow
- .claude/skills/django-model-skill.md - Guidance for creating Django models
- .claude/skills/react-component-skill.md - Guidance for creating React components
- .claude/skills/api-development-skill.md - Guidance for developing RESTful APIs
- .claude/settings.json - Editor configuration settings
- .claude/README.md - Explanation of the configurations

**Why:** 
To provide consistent development guidelines and reduce cognitive overhead for the CastraVision team. These configurations help maintain code quality, enforce best practices, and provide step-by-step guidance for common development tasks.

**How to apply:**
Team members should refer to these configurations when working on the CastraVision project. Claude Code will automatically detect and use these configurations when providing assistance. For specific tasks, team members can invoke the relevant skills (e.g., when creating a Django model, use the django-model-skill).
