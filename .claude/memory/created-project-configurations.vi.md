Created Vietnamese versions of rule and skill files for the CastraVision project in the .claude directory to help maintain code quality and provide development guidance for Vietnamese-speaking team members.

**What was created:**
- .claude/rules/code-review-rules.vi.md - Vietnamese version of comprehensive code review guidelines
- .claude/rules/project-guidelines.vi.md - Vietnamese version of overall project guidelines and workflow
- .claude/skills/django-model-skill.vi.md - Vietnamese version of guidance for creating Django models
- .claude/skills/react-component-skill.vi.md - Vietnamese version of guidance for creating React components
- .claude/skills/api-development-skill.vi.md - Vietnamese version of guidance for developing RESTful APIs

**Why:** 
To provide consistent development guidelines in Vietnamese for team members who prefer to work in their native language. These configurations help maintain code quality, enforce best practices, and provide step-by-step guidance for common development tasks.

**How to apply:**
Vietnamese-speaking team members should refer to these configurations when working on the CastraVision project. Claude Code will automatically detect and use these configurations when providing assistance in Vietnamese context. For specific tasks, team members can invoke the relevant skills (e.g., when creating a Django model, use the django-model-skill.vi).
